# EvidenceMatrix

Lokaler Assembler für Belegmatrizen aus CSV – ohne Upload, Konto oder Cookies.

- [Tool](em-tool.html) · [Landingpage](index.html)
- Kein ISO-Produkt, keine Zertifizierung, keine Beratung, keine Garantie für Auditannahme.
- Gratis: 5 Zeilen; Pro-Demo `?pro=1` lokal, ohne Lizenzserver.
