Häufige Fragen

Ist EvidenceMatrix eine ISO-27001-Software?

Nein. Es werden keine Normtexte oder Kontrollkataloge mitgeliefert. Das Tool strukturiert ausschliesslich deine eigenen Angaben und sagt keine Konformität zu.

Werden meine Daten hochgeladen?

Nein. Kein Server, kein Tracking, keine Cookies, keine externen Skripte oder Fonts. Eine Vorlage wird nur nach ausdrücklichem Klick lokal gespeichert.

Gibt es einen XLSX-Import?

Nein. Die Eingabe erfolgt über CSV mit wählbaren Trennzeichen. Es gibt keine Synchronisierung mit Cloud-Diensten.

Wie wird Pro aktiviert?

Über den lokalen Schalter ?pro=1 in der ausgelieferten ZIP-Datei. Kein Konto, kein Lizenzserver, keine Datenübertragung.

Garantiert das Tool eine Auditannahme?

Nein. Es erstellt eine Übersicht deiner eigenen Angaben. Es ersetzt keine Beratung und keine Prüfung durch Dritte.
