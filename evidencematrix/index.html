Deine Belege. Deine Matrix. Lokal.

EvidenceMatrix macht aus einer einfachen CSV-Liste eine druckbare Belegmatrix – mit Lückenliste und Fälligkeitsliste. Ohne Upload, ohne Konto, ohne Cookies.

Tool kostenlos testen Pro-Demo ansehen

Gratis: 5 Zeilen pro Analyse. Pro: unbegrenzte Zeilen, als lokaler Schalter ohne Lizenzserver. Verkaufslink folgt mit dem verifizierten Listing.

Kein ISO-Produkt, keine Zertifizierung, keine Beratung, keine Garantie für Auditannahme. Es werden keine Normtexte mitgeliefert.

Für wen?

  • Kleine Teams und SaaS, die eigene Nachweislisten für internen Gebrauch strukturieren
  • Alle, die Belege, Verantwortliche und Reviewdaten aus einer Tabelle in eine druckbare Matrix bringen wollen
  • Menschen, die ihre Unterlagen nicht auf einen fremden Server laden möchten

Wie es funktioniert

  1. CSV mit Kontroll-ID;Belegdatei;Datum;Status;Verantwortlich;Review;Notiz eingeben.
  2. Stichtag und Fenster wählen, auf „Analysieren“ klicken.
  3. Matrix drucken oder Lücken und Fälligkeiten als CSV exportieren.

Erkennt fehlende IDs und Belege, doppelte ID/Beleg-Kombinationen, offene oder abgelaufene Status sowie fällige Reviews. Keine Bewertung von Inhalten.

Häufige Fragen

Ist das eine ISO-27001-Software?

Nein. Das Tool strukturiert nur deine eigenen Angaben. Keine Normtexte, keine Konformitätsaussage, keine Beratung.

Werden Daten übertragen?

Nein. Kein Server, kein Tracking, keine Cookies, keine externen Skripte oder Fonts. Alles bleibt im Browser.

Kann ich es kommerziell nutzen?

Ja. Die Gratisversion ist kostenlos; die Pro-Datei wird über Gumroad angeboten, sobald das Listing verifiziert ist. Kein technischer Lizenzserver.
