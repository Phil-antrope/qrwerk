# QRWerk

Lokales Browser-Tool für Schweizer QR-Rechnungen aus CSV (SPC 0200, SIX IG v2.4).

- [Tool](tool.html) · [Landingpage](index.html)
- Kein Upload, kein Konto, keine Cookies, keine externen Skripte.
- Eingeschränktes MVP: Drucklayout vereinfacht, keine Bank-Zertifizierung.
- [Pro-Version](https://gumroad.com/l/focvs) CHF 39: lokal, ohne Upload, kein Lizenzserver.
- vendored QR-Bibliothek unter MIT-Lizenz (`LICENSE-qrcode-generator.txt`).
